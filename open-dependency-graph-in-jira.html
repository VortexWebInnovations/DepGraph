Where to open Dependency Graph in Jira

Dependency Graph opens wherever you plan work in Jira. Each place shows a dependency map of the issues there: one issue, a JQL search, a board, the backlog, a sprint or the whole site.

Don't see these places? Ask your Jira admin to update the app: Apps → Manage apps → Update.

Dependency Graph by VortexWeb Innovations is a Jira Cloud app to view and visualize Jira dependencies as an interactive dependency map, from blockers and linked issues to the full epic-to-subtask dependency tree. About 3,500 people use it on 185 Jira sites (October 2026).
